# 01. 운영체제와 커널 — 이해도 확인

상태: **답변 대기**

문서를 보지 않고 자신의 말로 답합니다. 정확한 전문용어보다 인과관계를
설명하는 것이 중요합니다. 답변은 채팅에서 작성하고, 평가와 보강 내용은
이 파일에 다시 반영합니다.

## A. 파인만 확인 질문

### Q1

컴퓨터를 전혀 모르는 사람에게 운영체제가 왜 필요한지 설명해보세요.

### Q2

운영체제와 커널은 무엇이 다른가요?

### Q3

애플리케이션이 디스크나 메모리를 직접 마음대로 제어하게 하면 어떤 문제가
발생할까요? 최소 두 가지를 말해보세요.

### Q4

운영체제가 관리하는 핵심 자원 네 가지와 각 역할을 설명해보세요.

### Q5

여러 프로그램이 동시에 실행되는 것처럼 보이는 이유를 CPU 관점에서
설명해보세요.

## B. 실무 연결 질문

### Q6

TIFF-to-PDF 처리에서 임시 PNG 파일 방식을 `MemoryStream` 방식으로 바꿨을 때
왜 성능이 개선되었는지 운영체제 관점으로 설명해보세요.

### Q7

임시 파일을 사용했다고 해서 매번 반드시 물리 디스크까지 접근했다고
단정할 수 없는 이유는 무엇인가요?

## C. 기술면접 질문

### Q8

“운영체제란 무엇인가요?”라는 질문에 60초 이내로 답해보세요.

### Q9

“커널이 없다면 애플리케이션이 하드웨어를 직접 사용하면 되지 않나요?”라는
꼬리 질문에 답해보세요.

## 평가 기준

| 항목 | 확인 내용 |
|---|---|
| 정확성 | OS와 Kernel의 역할을 잘못 설명하지 않는가 |
| 인과관계 | 기능 목록이 아니라 왜 필요한지 설명하는가 |
| 쉬운 표현 | 암기한 정의 대신 자신의 말로 말하는가 |
| 실무 연결 | 파일 I/O 사례와 연결할 수 있는가 |
| 꼬리 질문 | 보호, 충돌, 이식성 중 두 가지 이상을 말하는가 |
