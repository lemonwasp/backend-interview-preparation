상태: **답변 대기**

1. Backend에서 Heap Size뿐 아니라 Allocation Rate가 중요한 이유는?
2. Value Type과 Reference Type의 차이를 설명하라.

4. Boxing과 Unboxing은 무엇인가?

- Allocation Rate와 GC Pressure를 연결한다.
- Boxing을 정확히 설명한다.
- Value Type == Stack 같은 오해를 피한다.
- Pooling/Span을 만능 최적화로 표현하지 않는다.
