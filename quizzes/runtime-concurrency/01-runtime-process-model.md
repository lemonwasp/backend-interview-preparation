# Quiz — Runtime Process Model

상태: **답변 대기**

1. OS와 Runtime의 역할 차이를 설명하세요.
2. CLR이 제공하는 대표 기능 5가지를 말하세요.
3. `new User()`가 호출될 때마다 OS syscall이 발생한다고 보면 왜 틀린가요?
4. Managed Heap은 OS Virtual Memory와 어떤 관계인가요?
5. `Task`와 OS Thread가 같은 개념이 아닌 이유는 무엇인가요?
6. C# Source가 CPU에서 실행되기까지 IL/JIT 관점의 흐름을 설명하세요.
7. ".NET은 항상 JIT으로만 실행된다"가 왜 부정확한가요?
8. ASP.NET 요청 처리에서 Runtime 관점으로 볼 수 있는 병목을 3개 말하세요.
9. CPU scheduling과 ThreadPool scheduling의 담당 계층 차이는 무엇인가요?
10. GC 문제와 OS memory 문제를 어떻게 구분해서 생각해야 하나요?

## 평가 기준

- OS와 Runtime 추상화 계층을 혼동하지 않는다.
- managed heap과 virtual memory의 포함 관계를 설명한다.
- Task != Thread를 명확히 말한다.
- JIT/AOT를 과도하게 단순화하지 않는다.
- backend 장애와 연결할 수 있다.
