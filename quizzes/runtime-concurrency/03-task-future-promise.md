# Quiz — Task / Future / Promise

상태: **답변 대기**

1. Task와 Thread의 차이를 설명하세요.
2. I/O-bound Task가 미완료인 동안 전용 Thread가 필요하지 않을 수 있는 이유는 무엇인가요?
3. `Task.Run()`과 `HttpClient.GetAsync()`의 실행 특성 차이는 무엇인가요?
4. Continuation이 무엇인가요?
5. `Task.WhenAll()`이 여러 Thread의 병렬 실행을 의미하지 않는 이유는 무엇인가요?
6. `Task.WhenAll()`로 수천 개 DB 작업을 동시에 시작하면 어떤 문제가 생길 수 있나요?
7. Faulted Task와 `await`의 예외 전달 관계를 설명하세요.
8. fire-and-forget이 backend에서 위험한 이유는 무엇인가요?
9. `CancellationToken`이 강제 Thread 종료와 다른 이유는 무엇인가요?
10. C# Task, Java Future/CompletableFuture, JS Promise의 공통 추상화는 무엇인가요?

## 평가 기준

- 작업 표현과 실행 자원을 분리한다.
- continuation을 설명한다.
- concurrency와 parallelism을 혼동하지 않는다.
- cancellation/exception lifecycle을 설명한다.
- downstream resource limit과 연결한다.
